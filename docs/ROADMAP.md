# StudSync developer roadmap

This is the developer agent's queue. Before choosing work, reconcile fresh master, actual open PRs, branches/worktrees, issues and code under `AGENTS.md`. Distinguish implemented open work from merged work; do not recreate it. Review suggestions need a tested fix or concrete rejection. Use the owner's ChatGPT subscription, never OpenAI API credentials or API-billed Actions. No additional reviewer, scheduler, status publisher or merge bot is needed.

## Defaults and later distribution

Göttingen only, ordinary Finder folders and hourly sync by default. Never keep the Mac awake for sync. Preserve local edits, unknown files and incoming conflicts; never mirror remote deletion. No Finder extension or multi-university framework is planned. Developer ID/notarization, wider hardware support and broader distribution testing are later scope, beyond personal ad-hoc releases.
